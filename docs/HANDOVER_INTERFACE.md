# 交接接口（HANDOVER_INTERFACE）—— 模板与信箱规范

> **本文是什么**：`LEAD_GOVERNANCE.md` §4 的**可复制模板**。窗口之间只经**文件 + git** 交接（会话之间不能互发消息）。
> **归属**：总领窗维护。**三个信箱都在** `docs/HANDOVER_EXCHANGE/`。
> **共同纪律**：一次交接 = **一个文件** + **一个 commit**。缺任一 ⇒ 交接无效。

---

## 0. 信箱一览

| 文件 | 谁写 | 何时写 | 写作用域 |
|---|---|---|---|
| `INBOX-<窗>.md` | 总领窗 | 派活时（覆盖式，只放**当前**任务） | 总领窗 |
| `OUT-<窗>-<任务号>.md` | **板块窗** | 交付时（**只增不改**，历史留痕） | 板块窗 |
| `VERDICT-<任务号>.md` | 总领窗 | 验收后（通过/驳回都写） | 总领窗 |
| `BLOCKED-<任务号>.md` | 板块窗 | 遇阻塞时（**立刻写，不要硬扛**） | 板块窗 |

窗代号：`A`=地基窗、`B`=表达窗、`C`=契约窗、`D`=桌宠窗。

---

## 模板 1：任务卡（总领窗 → `TASK_BOARD.md` + `INBOX-<窗>.md`）

```markdown
## T-<编号> <标题>

- **目标**：<一句话，可验收>
- **归属窗口**：<A/B/C/D>（一窗一主人）
- **写作用域**：<精确路径，逐条列出；必须落在该窗作用域内>
- **前置依赖**：<T-xxx / 无>
- **验收门**：
  - [ ] `uv run ruff check`
  - [ ] `uv run ruff format --check`
  - [ ] `uv run mypy src`
  - [ ] `uv run pytest`（**基线 461 passed，不得下降**）
  - [ ] <该任务特有门：取消测试 / spine_verify / 真机验收 / …>
- **激活性取证**：<产生者是谁 + 在库里哪一行>
- **用户签认**：<需要 / 不需要>
- **状态**：待办
```

**派活者须同时确认三件事**（否则任务卡无效）：

1. 写作用域**未与其它窗重叠**（对照 `LEAD_GOVERNANCE.md §2.2`）
2. 前置依赖**已满足**
3. 验收门**在本任务上可完成**（不是套话）

## 模板 2：交接单（板块窗 → `OUT-<窗>-<任务号>.md`）

> **九字段，缺一即驳回**（总领窗不看内容直接退）。

```markdown
# 交接单 T-<编号> <标题>

| 字段 | 内容 |
|---|---|
| **① 任务号** | T-<编号> |
| **② 提交 SHA** | `<sha>`（`git show <sha>` 可复现） |
| **③ 变更文件清单** | `<路径>`（+行数/-行数）；**必须全部落在任务卡写作用域内** |
| **④ 门禁四件套实测输出** | 逐条贴**真实输出**（见下方"证据粘贴区"） |
| **⑤ 激活性取证** | 产生者：`<文件:行>`；库内证据：`<表 / key>` + `<实测查询结果>` |
| **⑥ 未做与已知限制** | 如实写。**"没有限制"需要有理由** |
| **⑦ 阻塞或依赖** | 无 / <依赖 T-xxx> |
| **⑧ 建议验收步骤** | <总领窗照此复现的最小步骤> |
| **⑨ 自检写作用域** | 我确认本次改动**未越界**：<是/否> |
```

## 模板 4：阻塞单（板块窗 → `BLOCKED-<任务号>.md`）

> **原则：遇阻塞立刻写，不要硬扛、不要猜、不要绕过。** 硬扛出来的东西必被驳回。

```markdown
# 阻塞 T-<编号>

- **阻塞类型**：写作用域冲突 / 依赖未完成 / 需用户签认 / 门禁环境问题 / 需求不清
- **具体现象**：<可复现的最小描述，含命令与报错原文>
- **我已尝试**：<做了什么，结果如何>
- **需要谁做什么**：<总领窗裁决 / 用户签认 / 其它窗先完成 T-xxx>
- **当前状态**：已停止本任务，未提交半成品（是/否）
```

```markdown
- **与现有四窗的零重叠核对**：<逐条对照，附命令输出>
```
