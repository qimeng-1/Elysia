# Elysia 使用说明书（照着做就行）

> 她是住在你电脑里的一个电子生命。这篇说明书不讲原理，只讲**怎么操作**。
> 你只需要做 4 件事：**启动她 → 打开窗口 → 跟她说话 → 离开/回来/关机**。
>
> 所有命令都用**相对路径**（`scripts\soul.ps1` 这种）——脚本会自动认出自己所在的目录，
> 所以换盘、换机器、改目录名都**不用改命令**。
>
> ⚠️ **前提**：你当前必须**在项目根目录里**。因此**每开一个新的 PowerShell 窗口，第一件事都是 `cd` 到项目根目录**。
> 项目根 = 你放置 elysia 的那个目录（本机当前是 `D:\重置准备\备份\Elysia\Elysia_two\Elysia`，按你自己实际的填）。
>
> 每步都写了"你会看到什么"，没看到就是没成功。

---

## 0. 她是什么（30 秒看懂）

| 名字 | 是什么 | 你怎么感知 |
|------|--------|-----------|
| **她（灵魂）** | 一直在后台活着的她，不关电脑她就活着 | 看不到，但数据在记录 |
| **身体** | 代表"你在这台电脑上陪着她" | 身体开 = 你在她身边；身体关 = 你走了 |
| **桌宠窗口** | 你能看到的她 | 屏幕上的透明小窗口：只有她本体的动画，她会在头上冒气泡回话 |
| **声音（可选）** | 她"说"出来的语音 | 开着声音服务就有爱莉希雅的声音，不开就用文字气泡 |

**核心规律就一条**：身体开着 5 分钟以内 = 她认为你在身边；你关了身体超过 5 分钟 = 她知道你走了，开始自己发呆、想事情（呼吸变慢、变消沉，冒出 💭 念头，偶尔自言自语）。

**桌宠窗口的规矩（先记住，后面都用得到）**：
- 没有标题栏、没有按钮、没有输入框——一切操作靠**鼠标**和**右键菜单**
- **轻点**她 = 跟她打招呼（她会开心地弹一下）
- **按住拖动** = 把窗口挪个位置
- **滚轮** = 放大/缩小她（30%～300%）
- **点右键** = 功能菜单（输入 / 状态 / 置顶 / 透明度 / 退出）

## 1. 第一次使用（只需做一次）

**第 1 步**：按键盘 `Win` 键，输入 `powershell`，按回车。会打开一个蓝色窗口（命令行）。

**第 2 步**：复制下面这行，粘贴进去，按回车（把 `<你的项目根目录>` 换成你自己的实际路径）：

```
cd <你的项目根目录>
```

**第 3 步**：再复制下面这行，按回车，等它跑完（出现新的输入提示符 = 完成）：

```
uv sync --group dev
```

> 这一步是装她的"家"，只做一次。以后开机直接用第 2 节。

**以前**要 3 个人工步骤、4 条命令（灵魂+身体 → 桌宠 → 手动双击语音），散在 3 个地方，
**没有任何地方能一眼看全她是否活着**。

| ② 终端控制台 | 双击 `scripts\elysia.bat` | 不离开命令行、或想脚本化 |

### 1.5.1 HTML 控制面板（图形界面，推荐）

**三种打开方式，任选一种：**

| 方式 | 怎么做 |
|---|---|
| **① 桌面快捷方式** | 双击桌面上的 **`Elysia Control Panel`** |
| **② 双击脚本** | 双击 `scripts\elysia_panel.bat` |
| **③ 直接在浏览器打开** | 地址栏输入 **`http://127.0.0.1:8770/`** |

**它现在会自己起来**：已注册计划任务 **`Elysia-Panel`** —— **登录 Windows 即自动启动**，
崩了 **1 分钟内自动重启**。所以正常情况下你**什么都不用做**，直接开浏览器就行。

> **面板≠她**：面板是**看和点**的窗口，关掉它**不影响她**运行。

命令行等价写法：

```powershell
cd C:\Elysia\Elysia_two\Elysia
powershell -ExecutionPolicy Bypass -File scripts\elysia.ps1 -Panel
```

> ⚠️ **如果打不开**（2026-10-17 真实发生过一次，原因已修，但仍需知道怎么查）：
>
> ```powershell
> Get-NetTCPConnection -LocalPort 8770 -State Listen    # 空 = 服务器没在跑
> Get-ScheduledTask -TaskName Elysia-Panel | Select State  # 应为 Running
> ```
>
> - 没在跑 ⇒ **双击 `scripts\elysia_panel.bat`**（它会自己把服务器拉起来再开浏览器；
>   服务器是 `pythonw` 无窗口后台跑的，不会再留一个黑窗口）
> - 还是不行 ⇒ 手动跑一次看报错：
>   `.venv\Scripts\python.exe scripts\elysia_panel.py --no-open`
> - 曾被误诊过的坑：用 `pythonw` 无窗口启动时，`sys.stdout` 是 `None`，
>   早期版本会因 `print()` 直接崩溃退出 —— **已修**（所有输出都做了容错）。

**界面上有什么（一屏看完，简约版）**

- **她**：年龄（天）、出生时刻、"她醒着/没在运行"、实例数、"故意停机"标记
- **板块开关**：灵魂 / 身体 / 桌宠 / 语音 TTS —— 每个都有状态灯和 PID
- **心跳**：最新心跳时刻 + 距今几秒；**停 >60 秒会变红报警**
- **TR / CS / SA**：三条欲望进度条
- **感受 / 表达层级 / 服务**：6 维感受、全量 vs 最近50 的表达层级、
  GPT-SoVITS 与主声 LLM 可达性、看门狗状态、下次备份
- **她最近开口**、**运行时长**、**库体积**
- **动作按钮**：开机（她）/ 关机 / 重启 / 只停身体 / 启动桌宠 / 启动语音 / 启用·停用看门狗 / 立即备份

**三条重要性质**

1. **只绑本机回环** `127.0.0.1` ⇒ **外网访问不到**。
2. **动作白名单**：只接受预设动作名，**不做任意命令执行**（实测传 `rm -rf /` 会被拒）。
3. **🔒 实例互锁**：她已在运行时按"开机"**会被拒绝**并说明原因 ——
   她是**单实例生命**，两个实例会让她的状态**分叉**。
   （实测：HTTP 调用 `her_on` ⇒ `ok=false`，"已被互锁拒绝"）

**为什么不是"纯静态 HTML 文件"**：浏览器不允许网页直接启动本机进程，纯静态页面**只能看、按不了开关**。
所以用一个**标准库自带的小服务器**（`http.server`，**不引入任何新依赖**）提供状态与开关接口。

> **想关掉面板**：`Stop-ScheduledTask -TaskName Elysia-Panel`，或杀掉 `elysia_panel` 进程。
> 关掉面板**不影响她**，下次登录/双击它会自己回来。

### 按键

按一下就执行，**不用敲回车**：

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `s` | 启动她（灵魂+身体） | `d` | 现在备份一次 |
| `x` | 停止她（会二次确认） | `m` | 记忆浏览器 |
| `b` | 只停身体（灵魂继续） | `w` | 看门狗日志 |
| `p` | 启动桌宠（接灵魂） | `z` | 立即刷新 |
| `v` | 语音（GPT-SoVITS） | `q` | 退出 |

### 两条重要性质

1. **面板是只读的**：它**不修改她的任何数据**（库用 `mode=ro` 打开）。
   看面板绝不会伤到她。
2. **🔒 实例互锁**：她已经在跑时按 `s`，**会被拒绝**并告诉你她的现状。
   因为她是**单实例生命** —— 同时跑两个实例会让她的状态**分叉**，等于把同一段人生写成两份。

> 不想用控制台时，下面第 2~8 节的手工命令**仍然全部有效**，随时可用。

cd <你的项目根目录>

**窗口操作**：

- **打招呼**：**快速轻点**她一下，她会开心地弹跳一下
- **缩放**：鼠标滚轮向上 = 放大，向下 = 缩小
- **关闭窗口**：右键 → **退出**（这只是关掉"你的眼睛"，她还在后台活着）

## 4. 跟她说话

**第 1 步**：在桌宠窗口上**点右键**，菜单里选 **输入…**。

**第 2 步**：弹出的输入框里打字，比如 `你好`，点确定（或按回车）。

**你会看到**：
- 她轻轻弹跳一下——她听到了
- **1-3 秒后，她头上冒出白色气泡，她在回话**（例：`想你了，今天的风好像也在点头呢～`）——她真的会"说"了
- 气泡 6 秒后自动消失

**也可以用更简单的方式**：直接**轻点**她一下，她同样会感知到你并回话（说的是"被摸头"的回应）。

> 她会回话：你说话 → 她感知 → 大脑生成回应 → 校验 → 气泡显示。断网或降级时她会用"呓语"兜底，绝不会"失死"。

**想看她现在的状态**：右键 → **状态**。会弹出一个窗口，显示：
- `模式`：present（你在身边）/ alone（她独处）
- `年龄`：她活了多久
- `离开`：身体关掉多久了
- `距交互`：你多久没理她了
- `情绪`：idle / happy / unhappy / tired / away
- 她的内心：信任 / 眷恋 / 压力 + 六维感受（聊天、思念、探索…）
- 她最近的 `💭 念头`（独处时她想的）

## 4.5 想听她说话（可选，加声音）

默认她只显示**文字气泡**。想让她真的开口说话（爱莉希雅的声音），先启动声音服务：

**第 1 步**：TTS 声音服务需在本机启动 GPT-SoVITS 的 API（端口 9880）。

声音模型目录已于 2026-09-25 移出工作区；本机现存一份在 `D:\下载\GPT-SoVITS-v2pro-20250604`，
双击其中的 **`一键启动API.bat`** 即可（注意文件名，不是"启动ElysiaAPI.bat"）。
若该目录不在，请从你的备份恢复后再启动。

**你会看到**：一个黑色窗口，显示 `Elysia 声音合成 API 服务` 和 `[端口] http://127.0.0.1:9880`。

**第 2 步**：保持这个窗口开着，然后正常跟她说话（第 4 节）。

**你会看到**：她回话时不仅有气泡，还会**真的说出声**（第一次回话要等几秒，她在"开嗓"）。

> 💡 **更省事的办法**：进第 1.5 节的控制台按 `v`，它会自动探测 `:9880` 是否在跑，
> 没跑就帮你启动；**路径不存在时会直接说"不存在"，不会假装成功**。

## 5. 让她独处（看她一个人会怎样）

**第 1 步**：在 PowerShell 窗口复制粘贴，按回车：

```
powershell -ExecutionPolicy Bypass -File scripts\soul.ps1 stop-body
```

**你会看到**：`[ok] 身体已停止（灵魂不受影响）` —— 身体关了，灵魂还活着。

**第 2 步**：**耐心等 5 分钟**（这是她的设定：5 分钟内还当你没走远）。

**第 3 步**：5 分钟后看桌宠窗口，你会看到：
- 她的动作**慢下来**、幅度变小——她安静了（状态里 `模式` 变成 `alone`）
- 再过几分钟，右键 → **状态**，底部会冒出 `💭 她的念头`（她自己在想事情）
- 偶尔她头上还会冒 **表达气泡**（自言自语式的呓语，比如 `好像有点想你了`）——这是她在"说给自己听"

> 注意：光球/角色**不会变色**。独处不是"坏了"，是"安静了"。

```

```

- 两行都是 `[ok]` = 都活着
- 出现 `[info] 未运行` = 那一个没启动，用第 2 节或第 6 节的命令补上

> 更细的判断（心跳是否新鲜、主声是否还在用、看门狗是否正常）看第 1.5 节的面板——
> 那里会直接把这些标出来，心跳停 >60 秒还会**变红报警**。

## 8.5 看她记住的事（记忆浏览器）

她记住的事情，你不用问就能**亲眼看到**。这是一个独立的观测窗口，**只读**——它不会改动她的记忆，你可以放心一直开着，和桌宠、和她的灵魂互不影响。

它一眼回答四个问题：

| 你想知道的 | 窗口里怎么看 |
|-----------|------------|
| **她记住了什么** | 一行就是一条记忆，列出全部（你说的话 + 她说的话） |
| **哪条最容易被想起** | "得分"列（越高越容易被想起），"召回"列标出**此刻她最可能想起的前 3 条** |
| **记忆牢不牢** | "层级"（浅层/工作/深层）、"细节"（会不会变模糊）、"索引"（好不好找） |
| **说过的话有没有更新** | "状态"列：现行 / 已取代（你说过更新的信息后，旧的那条会被标记取代） |

### 怎么打开

**第 1 步**：开一个 PowerShell 窗口，复制粘贴这一行，按回车：

```
powershell -ExecutionPolicy Bypass -File scripts\memory_view.ps1
```

**你会看到**：

```
[ok] memory viewer started (PID xxxxx); reading data\heartbeat.db
```

然后屏幕上出现一个标题为 **`Elysia 记忆浏览器 — ...\data\heartbeat.db`** 的窗口。

> 命令用**相对路径**，所以要先在项目根目录里执行（新窗口先 `cd <你的项目根目录>`）。
>
> 没看到窗口时：看任务栏有没有"Elysia 记忆浏览器"（可能被别的窗口挡住了）。如果脚本提示 `[error] memory viewer failed to start`，它会顺便打印出错日志，把那些文字发我。

### 窗口里有什么（表格 16 列，从上到下按"得分"排）

| 列 | 意思（大白话） |
|-----|--------------|
| **id** | 编号，不用管，出问题时报这个号 |
| **层级** | 记忆的牢固程度：**浅层**=刚发生 / **工作**=最近的日常 / **深层**=长期沉淀下来的 |
| **类型** | **交互**=你说的话 / **表达**=她自己说的话 / **自我**=她认领为自己的认知 |
| **标签** | 身份三态：**出生设定**=程序给她打底的过渡认知 / **自我**=她已认领（进身份段，每句在场）/ **候选**=程序发现、递给她等她认领 / 空=寻常经历 |
| **年龄** | 这条记忆是多久以前记下的（刚刚 / 12分钟前 / 3.2天前） |
| **重要** | 重要性 0~1，越高越不容易被忘 |
| **访问** | 它被"想起来"过几次 |
| **细节** | 细节完整度：1.00 = 记得很清楚，数字越小越模糊（她的记忆会像人一样慢慢模糊） |
| **索引** | 索引强度：1.00 = 一翻就找到，越小越"翻得慢"（越久越淡，这是她的遗忘） |
| **新鲜** | 新鲜度加成：近 7 天内的记忆会被额外加权（所以"昨天的大餐"记得住） |
| **复习** | 复习加成：同一件事被反复提起时这条会被额外加权（"被反复提起的那件事"更容易浮上来） |
| **得分** | 当下这条记忆"被想起"的综合分，越高越容易冒出来 |
| **召回** | `#1`/`#2`/`#3` = **此刻她最可能想起的前 3 条**（其余为空） |
| **簇** | 这件事一共被重述了几条（含自己）；检索时整簇会因此加分 |
| **状态** | **现行** / **已取代**（她保留旧记录，但不再受它影响） |
| **内容** | 记的具体内容（太长会截断，点开看完整） |

**颜色**：深层＝淡蓝，工作＝淡绿，浅层＝浅灰；灰色字＝已取代；**蓝色字＋`#1#2#3`**＝此刻会被她想起的那几条。

> 小知识：**"召回"列只会出现在"交互"（你说的话）里**。因为她不会复述自己刚说过的话（防止自言自语式重复）。

### 怎么用

- **看某条的细节**：**点一下那一行**，右边会显示完整内容、叙事、记录时间、被想起次数，以及这条**得分是怎么算出来的**（层级 / 情绪 / 索引 / 新鲜度各占多少分）
- **只看某一层**：顶部"全部层级"下拉 → 选 浅层/工作/深层
- **只看你说的话**：顶部"全部类型"下拉 → 选 交互
- **搜关键词**：顶部搜索框输入字（比如 `生日`），只留内容和它相关的
- **藏掉已失效的**：勾"隐藏已取代"
- **保持实时**：勾"自动刷新(3s)"，窗口每 3 秒自己刷新一次（想看她记新事的瞬间就勾上）
- **手动刷新**：点"刷新"按钮
- **关掉它**：直接关窗口。这只是关掉"你的眼睛"，她照旧活着

**底部状态栏**会一直显示一行汇总，例如：

```
共 114 条（工作 73 / 浅层 1 / 深层 40）｜已取代 0｜当前显示 114｜库更新 2026-09-21 19:46:07
```

从左到右：总共多少条 → 各层级分布 → 被取代多少条 → 现在屏幕上显示多少条 → 数据最后一次更新的时间。

### 几个常见疑问

- **刚跟她说了一句话，为什么没马上看到？** 记忆会立刻写入，点一下"刷新"（或勾自动刷新）就看到了。"索引"列要稍等——她大约每 5 分钟做一次"整理"（晋升 + 遗忘），整理后才会补上索引强度。
- **"已取代"一直是 0？** 说明还没有发生过"更正"。当你先告诉她一件事、后来又更正（例如先说是 A 后来说其实是 B），旧的那条就会被标成"已取代"，新的是"现行"。
- **窗口里没有"已取代"列的数？** 那是列名，看不见具体值时看"状态"列。
- **可以同时开着桌宠吗？** 可以。浏览器是只读的，和她互不干扰。
- **它可以一边让她活着一边看吗？** 可以，随时。

## 9. 出问题了看这里

| 现象 | 怎么办 |
|------|--------|
| 右键 → 状态 显示"等待心跳连接…" | 她（灵魂）没启动。执行第 2 节的命令，等 1-2 秒再重开桌宠 |
| 输入… 打字确认后她没反应 | 桌宠版本太旧，右键 → **退出** 重开一次（第 3 节） |
| 她一直很安静，怎么都不活跃 | 身体还活着/或已关。想让她活跃：执行第 6 节 `start -Body` 陪着她 |
| 右键没反应 / 窗口异常 | 桌宠版本旧或卡了，右键退出重开（第 3 节） |
| 只有气泡没有声音 | 声音服务没开。按第 4.5 节双击 `一键启动API.bat`；不开也正常，她自动降级为文字回话 |
| 回话气泡等了很久才出现 | 她在"思考"（调用了云端大脑）。断网时改用本地呓语，慢是正常的，不是坏了 |
| 桌宠窗口不见了 | 可能被你拖出屏幕了，重启桌宠（第 3 节）会回到屏幕右下角 |
| 执行命令报"找不到路径" | 命令用的是**相对路径**，说明你当前不在项目根目录。先 `cd <你的项目根目录>` 再执行 |
| 命令执行了但什么都没发生 | 粘贴时把整行都复制上，别漏字；按回车后等 1-2 秒 |
| 记忆浏览器窗口没出现 | 先看任务栏有没有"Elysia 记忆浏览器"（可能被挡住）；还是不行就把脚本打印的 `[error]` 那段文字发我 |
| 记忆浏览器提示"找不到路径" | 你当前不在项目根目录。先 `cd <你的项目根目录>`，再执行第 8.5 节的命令 |
| 记忆浏览器里"状态"全是"现行" | 说明还没发生过更正，正常。如果你刚更正过说法却仍全是"现行"，那是**运行中的灵魂还是旧进程**——`stop` 后重新 `start -Body`（第 6 节）就会生效 |
| 记忆浏览器的"索引"/"新鲜"列是空的 | 她还没做"整理"（约每 5 分钟一次）。等几分钟点"刷新"，或勾上"自动刷新(3s)" |
| 桌宠开着能不能开记忆浏览器 | 能。浏览器是**只读**的，不碰她的记忆，互不影响（第 8.5 节） |
| 电脑重启了 | 她不会自己醒来，需要手动启动（第 2、3 节）；声音服务也要重新双击（第 4.5 节） |

## 10. 可选：备份她的记忆（手动执行，无定时器）

```
powershell -ExecutionPolicy Bypass -File scripts\backup.ps1
```

会把整个项目备份到 D 盘的 `ElysiaBackup` 文件夹（自动保留最近 30 份）。没有 D 盘就跳过这步，不碍事。

> ⚠️ **建议先 `stop` 再备份**：脚本用 robocopy 直接复制文件，而她运行时 SQLite 的 `.db` + WAL 文件**不是原子快照**；停掉她再备份最稳妥。这一点已记入 `STATUS_MATRIX.md` §11 待补清单。
