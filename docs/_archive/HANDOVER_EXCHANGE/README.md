# HANDOVER_EXCHANGE —— 窗口间唯一信箱

> **为什么有这个目录**：会话之间**不能互相发消息**（总纲 §5 铁律 3）。⇒ 交接**必须**落在**仓库内的文件**上，否则窗口一关信息就没了。
> **规矩**：规则见 [LEAD_GOVERNANCE.md](../LEAD_GOVERNANCE.md) §4；模板见 [HANDOVER_INTERFACE.md](../HANDOVER_INTERFACE.md)。
> **一次交接 = 一个文件 + 一个 commit**，缺任一即**无效**。

## 四种文件

| 文件 | 谁写 | 何时 | 性质 |
|---|---|---|---|
| `INBOX-<窗>.md` | 总领窗 | 派活时 | **覆盖式**（只放当前任务） |
| `OUT-<窗>-<任务号>.md` | 板块窗 | 交付时 | **只增不改**（历史留痕） |
| `VERDICT-<任务号>.md` | 总领窗 | 验收后 | 通过/驳回**都写** |
| `BLOCKED-<任务号>.md` | 板块窗 | 遇阻塞**立刻**写 | 不要硬扛、不要猜、不要绕过 |

窗代号：`A`=地基窗(core+soul+memory) · `B`=表达窗(llm+tts) · `C`=契约窗(protocol+tools) · `D`=桌宠窗(body+assets/pet)

## 铁律

1. **缺字段即驳回**：交接单 9 字段（`HANDOVER_INTERFACE.md` 模板 2）缺一，总领窗**不看内容直接退**。
2. **锚点是 commit**：交付前**先自己 commit**（只提交自己写作用域的文件），交接单里贴 SHA。
3. **不越界**：变更文件必须全部落在任务卡写作用域内。越界 = 驳回。
4. **不静默**：阻塞、限制、未做项**必须写出来**。"没有限制"要有理由。
5. **窗口不得自行开新窗**：只能向总领窗申请（模板 5）。
